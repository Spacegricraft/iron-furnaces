## About

Iron Furnaces gives smelting a progression. Iron, gold, diamond, emerald, obsidian, crystal and netherite furnaces each smelt faster, burn fuel more efficiently, and accept augments — auto input/output, fuel efficiency, generator mode and factory upgrades.

---

## Features

- Seven furnace tiers from iron to netherite with rising speed and efficiency
- Augment system: auto-split, fuel efficiency, generator and factory modes
- Upgrade path preserving contents when moving between tiers
- Optional colouring/decorative variants for base aesthetics
- Works with hoppers, pipes and automation from any mod

## Installation

1. **Download** the JAR matching your Minecraft version from the table above.
2. **Install a mod loader** — Forge, Fabric or NeoForge for your exact game version.
3. **Place the `.jar`** into your `.minecraft/mods/` folder (create it if it is missing).
4. **Launch** Minecraft using the modded profile.
5. Verify **Iron Furnaces** appears in the in-game mods list.

> **Tip:** if the game crashes on startup, you almost certainly mixed a Legacy JAR with a Modern
> Minecraft version, or are missing a required dependency. Check `latest.log` first.

## FAQ

**Q: Can I upgrade a furnace in place?**
A: Yes, upgrade recipes convert a lower tier to the next while keeping it functional.

**Q: What do augments do?**
A: They change behaviour — automatic input/output, better fuel use, or converting furnace output to energy.

**Q: Does it use power?**
A: No, they burn ordinary fuel — the generator augment can produce power instead.

**Q: Is it safe to add to an existing world?**
A: Yes in most cases — back the save up first, as you should with any mod addition.

**Q: Can I use it in a public modpack?**
A: Yes. Both builds are modpack-ready and require no additional setup.
